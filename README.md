# Movie Theater Seat Reservation API

OpenAPI 3.0 design for the seat reservation step of buying movie tickets online (CIS 4930 A7, REST API Design).

- `openapi.yaml`: the API specification (GET seat map, POST reservation, DELETE reservation)
- `sequence-diagram.png`: UML sequence diagram of the full ticket purchase flow
- `make_diagram.py`: the script that draws the diagram (`python3 make_diagram.py`, needs matplotlib)

This is a design only. Nothing here is implemented.
